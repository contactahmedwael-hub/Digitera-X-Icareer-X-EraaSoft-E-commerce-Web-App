# Odoratus — Perfume E-commerce Web App

This is the **final project** of the **Product Engineering Internship** by **Digitera**, **iCareer** and **EraaSoft**.

🔗 **Live demo:** [digitera-x-icareer-x-eraa-soft-e-co.vercel.app](https://digitera-x-icareer-x-eraa-soft-e-co.vercel.app/)

## Project Life Cycle

The project followed a full product life cycle:

1. **BRD** — Business Requirements Document
2. **PRD** — Product Requirements Document
3. **Backlog** — user stories and tasks
4. **Development** — building the app
5. **Testing** — unit and end-to-end tests
6. **Deployment** — live on Vercel

## Features

- Browse, search, filter and sort products
- Product details with bottle size and gift wrapping
- Shopping cart and checkout
- Order invoice sent through WhatsApp
- Login and sign up (demo)
- English and Arabic, dark and light mode

## Tech Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · TanStack Query · Zustand · Jest · Cypress
